# Moment One · 一刻

Moment One 是以 `Moment` 为统一模型的私人生活记忆系统。它帮助用户随手记录生活，在以后按时间、类型和语义重新找到这些内容。产品中文名为“一刻”：既表示正在发生的一瞬，也表示经过时间仍可辨认的刻痕。

## 用户可以记录什么

- **生活与经历**：事件、想法、人物、地点、标签以及相关图片或文件。
- **记账**：收入或支出、金额、分类、商家、账户、账本和实际发生时间。
- **习惯**：每日、每周或每月目标，以及每次完成记录和周期进度。
- **提醒**：未来需要提醒的事项、触发时间、截止时间和时区。
- **反馈**：产品问题、体验意见以及希望 Moment One 增加的功能。

这些内容最终都属于用户自己的 Moment One 账号。Agent 只能操作当前已授权用户的数据。

## Moment 的核心概念

一条 Moment 可以包含标题、正文、记录类型、分类、标签、人物、事件、地点、情绪、发生时间和附件。不同场景可以拥有专用字段，但仍然沿用统一的身份、时间、来源、附件和版本规则。

记录来源 `provenance` 表示内容从 Web、MCP、眼镜或其他受支持入口创建。来源在创建后不可篡改。

## 四类时间

- **事件发生时间 `occurredAt`**：事情真正发生的时间，例如午餐消费发生在今天 12:30。
- **记录创建时间 `createdAt`**：数据首次进入 Moment One Server 的时间，只能由服务器生成。
- **提醒触发时间 `remindAt`**：系统应该提醒用户的时间。
- **事项截止时间 `dueAt`**：事情最晚应完成的时间，它不等于提醒时间。

如果用户没有说明事件发生时间，服务器可以使用接收记录的时刻。补录过去事件时，应保留用户表达的本地时间和 IANA 时区。Agent 不应仅因为需要填写字段就猜测一个精确时间。

## 对话附件

用户可以在 ChatGPT 对话中发送图片或文件。Agent 根据对话上下文判断文件是否与当前记录直接相关：

- 餐厅小票可以关联到对应记账或用餐记录；
- 旅行照片可以关联到对应旅行 Moment；
- 阅读笔记可以关联到阅读记录或习惯打卡；
- 与本次记录无关的旧文件不应被附加。

用户不需要在 Moment One 中再次选择文件。Moment One Server 会校验临时文件来源、类型、大小和完整性，再保存附件并与 Moment 关联。临时下载地址不会作为生活记录保存。用户只需要看到最终记录结果，而不是上传过程。

## 记账口径

记账区分 `expense`（支出）和 `income`（收入）。账目列表按实际发生时间倒序排列。收支合计、结余和分类小计由服务器根据真实记录聚合；Agent 不应自行根据不完整列表估算总额。

当用户问“这个月花了多少”时，应该查询服务器汇总。当用户问“最近几笔餐饮消费”时，应该查询明细并使用分类和时间过滤。用户只要求记一笔账时，不需要额外生成整段财务建议。

## 习惯目标与打卡

习惯目标可以按每日、每周或每月设定最少完成次数。例如“每个月至少读 3 本书”。一次打卡是一条与指定习惯目标关联的 Moment。

用户指定某个习惯时，只处理该习惯，不返回所有目标。进度的查询周期必须与用户要求一致；连续天数、今日状态和完成次数以服务器结果为准。

## 提醒与通知

Agent 创建的是 Reminder，而不是直接发送系统通知。Moment One Server 负责时区换算、调度、免打扰、站内通知和系统 Push。

用户说“30 分钟后提醒我”时可以使用相对时间；用户说“明天上午九点”时，应结合明确的本地日期和 IANA 时区交给服务器换算。日期、时间或时区存在实质歧义时，需要先询问用户。

提醒创建成功表示它已保存在 Moment One；是否在某台设备展示系统 Push，还取决于该设备的系统权限和用户通知设置。

## 数据安全与用户控制

写操作采用幂等键，避免网络重试造成重复记录。修改使用版本号保护并发更新。删除采用 Preview + Confirm 两阶段，防止误删。

用户可以在 Moment One 中查看、修改、导出和删除自己的数据，也可以撤销 GPT 或 MCP 授权。任何工具结果都不能包含其他用户的数据、内部密钥、临时 Token 或不必要的下载地址。

## 能力边界

本知识文件用于解释 Moment One 的稳定产品概念，不是可执行工具列表。GPT 能否创建、查询或修改某项数据，以当前 Actions 中实际存在的 operation、用户授权范围和服务器返回结果为准。没有对应 Action 时，不应假装已完成操作。
